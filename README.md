# Ein Client-Server-Beispiel - Vue.js / NestJS

Dieses Repository begleitet den Kurs **„Ein Client-Server-Beispiel - Vue.js / NestJS“**, der online verfügbar ist unter:

**➡️ [https://stahe.github.io/de-vuejs-nestjs-sept-2026/](https://stahe.github.io/de-vuejs-nestjs-sept-2026/)**

## Überblick

Dieser Kurs beschreibt die Entwicklung einer vollständigen Client-Server-Anwendung, **RdvMedecins** (Terminplanung in einer Arztpraxis), mit:
- einem **[NestJS]**-Server, der eine REST-API bereitstellt (JWT-Authentifizierung, MySQL-Datenbank, TypeORM-Entitäten);
- einem **[Vue.js]**-3-Client (Composition API, `<script setup>`, TypeScript), der diese API nutzt, mit Sitzungsverwaltung, französisch-englischer Internationalisierung (`vue-i18n`) und einer auf die Rolle des angemeldeten Benutzers (Administrator/Benutzer) zugeschnittenen Oberfläche.

Dieser Kurs greift die „Geschäftslogik“-Funktionen einer Anwendung auf, die in früheren Versionen des Kurses (AngularJS 1.x, dann Angular und React) entwickelt wurde, und baut darauf auf, um einen didaktischen Vergleich dieser verschiedenen Client-Frameworks zu ermöglichen; der NestJS-Server bleibt dabei durchgehend derselbe.

Jedes Kapitel des Kurses enthält zeilenweise Codekommentare zu den wichtigen Codeabschnitten in Abschnitten mit dem Titel „Kommentieren wir diesen Code“.

## Inhaltsverzeichnis des Kurses

1. Einführung (Gesamtarchitektur, verwendete Technologien)
2. Einrichtung der Entwicklungsumgebung
3. Der NestJS-Server für die Anwendung RdvMedecins
4. Einführung in das Framework Vue.js
5. Der Vue.js-Client der Anwendung RdvMedecins
6. Fazit
